
# 📊 Flipkart Sales Analysis Dashboard (Microsoft Excel)

## 📌 Project Overview

This project is an interactive **Flipkart Sales Dashboard** built using **Microsoft Excel**. It analyzes sales performance, customer behavior, product categories, payment methods, and monthly trends. The dashboard provides valuable business insights through Pivot Tables, Pivot Charts, KPIs, and Excel formulas.

---

## 🎯 Project Objectives

- Analyze overall sales performance.
- Track monthly sales trends.
- Identify top-performing product categories.
- Compare sales across different brands.
- Analyze payment methods used by customers.
- Monitor order status distribution.
- Understand customer rating distribution.
- Create an interactive dashboard using slicers.
